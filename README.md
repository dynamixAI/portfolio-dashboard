# Portfolio Dashboard

An interactive dashboard that showcases my coding projects, built with Python (Flask) 
and Chart.js instead of a static webpage.

## What it does

- Pulls my public repositories live from the GitHub API
- Displays each project as a card (name, description, language, stars, last updated)
- Visualises language usage across projects with a Chart.js chart
- Updates automatically as I push new commits — no manual editing needed

## Tech stack

- **Backend:** Python, Flask
- **Frontend:** HTML, Chart.js
- **Data source:** GitHub REST API
